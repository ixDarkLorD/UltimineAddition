# Certificates and Mine-Go Juice

There are three ways to Ultimine. They stack: whatever you have unlocked for the tool in your hand is what you can use.

| | Unlocks | For | Lasts |
|---|---|---|---|
| **Shape Certificate** | One shape | One tool | For good |
| **Mine-Go Juice** | Every shape | One tool | While the effect lasts |
| **Miner Certificate** | Every shape | Any item | For good |

## Shape Certificates

Each time a Mining Skill Card reaches a new tier, it lets you claim one Shape Certificate for that card's tool.

1.  Open the card in the [Skills Record](skills-record.md) and claim the tier's reward.
2.  Pick a shape. The choice is that tier's list, plus any shape from an earlier tier you passed over.
3.  Use the certificate you receive. The shape is learned for that tool permanently.

The default lists:

| Tier | Shapes offered |
|---|---|
| Novice | Small Square |
| Apprentice | Escape Tunnel, Mining Tunnel |
| Adept | Small Tunnel, Large Tunnel |

Servers can change the lists, and decide which certificate picks up shapes that no list names (such as ones other mods add). A higher certificate tier also raises how many blocks one Ultimine can break with that tool.

Holding a tool with no shape learned shows "No Shape Learned" in FTB Ultimine's shape display.

### Shape Selector

The Shape Selector is a craftable item that lists the shapes and lets you assign the one you want to the tool you're using, instead of cycling through them.

## Mine-Go Juice

Mine-Go Juice is a potion with one variant per tool. While its effect lasts, you can Ultimine with every shape using that tool.

- It is brewed in a brewing stand from a Novice, Apprentice or Adept Mining Skill Card that has potion points left (the pips along the bottom of the card). Brewing spends them, and the card gets a full set again when it tiers up.
- The higher the card's tier, the longer the juice lasts.
- Splash and lingering versions and tipped arrows exist too.
- With the `tier_up_taste` server setting on, a card that tiers up gives you a short free taste of its juice.

## Miner Certificate

The Miner Certificate is the end of the road: Ultimine with every shape, with any item, for good.

Craft it from a paper and all four **Mastered** cards (pickaxe, axe, shovel and hoe), then use it.

### Completion Envelope (Legacy mode)

In [Legacy mode](../getting-started.md#playstyle-modes) the certificate starts as a sealed **Completion Envelope**, crafted from paper and four tools. It asks you to mine a number of ores; once you have, it opens into the Miner Certificate.
